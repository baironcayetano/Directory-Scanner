# Overview
Directory Scanner is a CLI tool to scan the structure of a directory. 
When you run the directory scanner program, the program will use the current directory from which it has been called and will display its content.

The main porpuse of this sofware is to provide a simple way to check directories from the console, helping developers or expert users understand the structure without having to run and memorize additional commands to read each directory and sub-directory.

This helps a lot when trying to find a file directly from the console.
Anyone running a server with node.js can install this program.
